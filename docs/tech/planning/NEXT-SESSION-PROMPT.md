## Что решено и не надо перерешивать

**Кураторство — свойство не экспириенса, а всего, что видит читатель.** Экспириенс, локация и
артефакт получают одни и те же три состояния: невидимо / показано-непроверено / человек проверил
то, что показано сейчас. Продукт уже отслеживает все три персонально — есть таблицы посещённых
объектов, посещённых точек и просмотренных артефактов.

Из этого следует остальное, и всё это записано в `catalogue-curation-model.md`: доверие
настраивается на источник; у того, чего никто не видел, защищать нечего; содержимое невидимого
контейнера едет вместе с ним; карточка куратора группируется по контейнеру, а решения
принимаются построчно; у артефакта состояние на самом артефакте, а цикл «он здесь» — на связи с
музеем; прогон, увидевший сильно меньше прежнего, не имеет права заключать, что что-то исчезло.

**И главное: ничего не удаляется, только помечается.** Сегодня, когда источник перестаёт
предлагать точку, строка удаляется, а каскадом уходят отметка человека о посещении и ручные
кураторские привязки к регионам — то самое, что чинил PR #495.

## Правила, которые действуют всегда

- **Думай сначала как эксперт по продукту, потом как инженер.** Мерь на реальных данных: база в
  одном `docker exec`, Wikidata в одном `curl`. За эту сессию так были найдены и отсутствующий
  Лувр, и музей по имени «Q214867», и прогон, потерявший две трети картин и отчитавшийся об
  успехе. Ни одно из этого не выводится рассуждением.
- **Гейты перед каждым коммитом:** `npm run check`, `TEST_REPORT_LOCAL=1 npm test`,
  `npm run test:py`, `/security-check`. Перед пушем — `npm run security:all` и
  `npm run test:e2e:smoke`. Python-гейты на этой машине идут только через Docker
  (`python3.12` отсутствует) — `scripts/require-py-tools.sh` печатает нужную команду.
- **Проверяй код возврата, а не грепай вывод.** `npm run … | tail -40` вернёт код `tail`.
- **Читай файл перед правкой.**
- **Никогда `git add -A <dir>`**, если в каталоге есть untracked-файлы.
- **Планы не коммитятся.** `docs/tech/planning/` — локальные рабочие документы; резервная ветка
  не в счёт и не мержится. Коммитится документация о том, что существует.
- **Проверяй на живой базе, а не на моках.**
- Перед PR: ни один коммит не должен существовать только чтобы починить предыдущий коммит той же
  ветки. Складывать через `/pr-changes-amend`.
- Отвечай по-русски; идентификаторы, пути и всё, что уходит в репозиторий, — по-английски.
